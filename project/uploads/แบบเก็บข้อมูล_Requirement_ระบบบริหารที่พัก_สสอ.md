# คำแนะนำในการให้ข้อมูล

กรุณาให้ข้อมูลตามการปฏิบัติงานจริงในปัจจุบัน หากมีแบบฟอร์ม Excel รายงาน หรือเอกสารที่ใช้งานอยู่ กรุณาแนบตัวอย่างประกอบ โดยสามารถระบุเพิ่มเติมได้ว่า ระบบใหม่ควรปรับปรุงหรือเปลี่ยนแปลงจากวิธีเดิมอย่างไร

# 1. ข้อมูลอาคารและสถานที่พัก

| ลำดับ | คำถาม/ข้อมูลที่ต้องการ | ข้อมูลปัจจุบัน / คำตอบ | ความต้องการระบบใหม่ / หมายเหตุ |
| --- | --- | --- | --- |
| 1 | ชื่ออาคารที่พักทั้ง 3 อาคาร และชื่อ/รหัสที่ใช้เรียกในงานจริง |  |  |
| 2 | จำนวนชั้นของแต่ละอาคาร |  |  |
| 3 | จำนวนห้องพักทั้งหมดของแต่ละอาคาร |  |  |
| 4 | อาคาร/ชั้นใดมีข้อจำกัดการใช้งาน เช่น แยกชาย–หญิง ผู้บริหาร วิทยากร หรือผู้พิการ |  |  |
| 5 | มีพื้นที่หรือห้องส่วนกลางใดที่เกี่ยวข้องกับการเข้าพักหรือไม่ |  |  |
| 6 | มีช่วงเวลาที่อาคารบางส่วนปิดใช้งานหรือมีเงื่อนไขพิเศษหรือไม่ |  |  |

# 2. ข้อมูลห้องพักและเตียง

| ลำดับ | คำถาม/ข้อมูลที่ต้องการ | ข้อมูลปัจจุบัน / คำตอบ | ความต้องการระบบใหม่ / หมายเหตุ |
| --- | --- | --- | --- |
| 1 | เลขห้อง/ชื่อห้อง อาคาร ชั้น และประเภทห้อง |  |  |
| 2 | จำนวนเตียง และจำนวนผู้เข้าพักสูงสุดของแต่ละห้อง |  |  |
| 3 | ประเภทเตียง เช่น เตียงเดี่ยว เตียงคู่ เตียงเสริม |  |  |
| 4 | สิ่งอำนวยความสะดวกที่ต้องการบันทึก เช่น แอร์ ทีวี ตู้เย็น Wi-Fi ห้องน้ำ เครื่องทำน้ำอุ่น |  |  |
| 5 | สถานะห้องที่ใช้จริง เช่น ว่าง จองแล้ว มีผู้พัก ปิดซ่อม ทำความสะอาด |  |  |
| 6 | มีห้องพิเศษ เช่น ห้องผู้บริหาร ห้องวิทยากร ห้องผู้พิการ หรือห้องสำรองหรือไม่ |  |  |
| 7 | ต้องการบริหารในระดับ 'ห้อง' หรือจำเป็นต้องบริหารถึงระดับ 'เตียง' |  |  |

| --- | --- | --- | --- |

| 2 | ข้อมูลผู้เข้าพักที่จำเป็นต้องบันทึก เช่น ชื่อ–สกุล เลขประจำตัว โทรศัพท์ อีเมล ตำแหน่ง |  |  |
| 3 | ต้องเก็บข้อมูลสถานศึกษา/หน่วยงาน จังหวัด ภาค และสังกัดหรือไม่ |  |  |
| 4 | ต้องบันทึกเพศ อายุ หรือข้อมูลที่จำเป็นต่อการจัดห้องใดบ้าง |  |  |
| 5 | อนุญาตให้มีผู้ติดตามหรือไม่ และมีเงื่อนไขอย่างไร |  |  |
| 6 | มีความต้องการพิเศษที่ต้องบันทึกหรือไม่ เช่น ผู้สูงอายุ ผู้พิการ ห้องชั้นล่าง |  |  |

# 4. ข้อมูลโครงการและการฝึกอบรม

| ลำดับ | คำถาม/ข้อมูลที่ต้องการ | ข้อมูลปัจจุบัน / คำตอบ | ความต้องการระบบใหม่ / หมายเหตุ |
| --- | --- | --- | --- |
| 1 | ข้อมูลโครงการที่ต้องใช้ เช่น รหัสโครงการ ชื่อโครงการ รุ่น วันที่อบรม สถานที่ และผู้รับผิดชอบ |  |  |
| 2 | ผู้เข้าพักทุกคนต้องผูกกับโครงการฝึกอบรมหรือมีผู้เข้าพักทั่วไปด้วย |  |  |
| 3 | หนึ่งโครงการมีหลายรุ่นได้หรือไม่ และแต่ละรุ่นมีช่วงพักต่างกันหรือไม่ |  |  |
| 4 | ใครเป็นผู้ส่ง/นำเข้ารายชื่อผู้เข้าอบรมและรายชื่อผู้ต้องการที่พัก |  |  |
| 5 | ปัจจุบันมีฐานข้อมูลหรือระบบรายชื่อผู้เข้าอบรมที่ควรเชื่อมต่อหรือไม่ |  |  |

| 2 | ผู้เข้าพักจองเอง หรือผู้รับผิดชอบโครงการ/เจ้าหน้าที่จองให้เป็นกลุ่ม |  |  |
| 3 | ต้องมีการอนุมัติหรือไม่ หากมี ใครเป็นผู้อนุมัติ และมีกี่ขั้นตอน |  |  |
| 4 | สามารถจองล่วงหน้าได้กี่วัน/เดือน และมีช่วงเวลาปิดรับจองหรือไม่ |  |  |
| 5 | ระบบควรแสดงห้องว่างให้ผู้จองเลือกเอง หรือให้เจ้าหน้าที่เป็นผู้จัดห้อง |  |  |
| 6 | ต้องมีเลขที่การจองหรือเอกสารยืนยันการจองหรือไม่ |  |  |
